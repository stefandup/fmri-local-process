# fMRI Local Process

A locally installable fMRI toolbox. The first working step is the
[Philani DICOM → BIDS conversion](bids-conversion.md) (`fmri_convert_to_bids`, plus
`fmri_behav_events` for single behavioural logs). Preprocessing, QC and the region
timeseries viewer are still at the planning stage; see the README.
